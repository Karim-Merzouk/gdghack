Secured 2nd place at the GDG internal Hackathon! 🎉

Our project, PathWay, is an AI-powered learning and networking platform that helps students and career switchers:
✅ Find personalized learning paths using Groq’s cloud-based LLM
✅ Match with peers for collaborative learning using ChromaDB
✅ Explore real-world hackathons & meetups based on skill level
✅ Enhance learning through AI-driven quizzes

As the AI Responsible Part, I focused on integrating:
🤖 FastAPI for a scalable backend
📊 ChromaDB for efficient skill-based matchmaking
💡 Groq’s LLM to generate intelligent, adaptive learning roadmaps
✨ AI -generated Quizzes for completing the RoadMap
